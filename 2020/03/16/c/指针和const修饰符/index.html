指针和const修饰符

Created2020-03-16|Updated2026-08-10|programming languages
|Post Views:

前言

  • 声明一个int类型的指针
    int * p

  • 一个变量
    int x

  • 随即，赋地址
    p = &x;

  • 到了这里，p就是x变量的地址。
    *p 就是x的值。


示例

  1. const float * p
  2. float const * p　　／／１．２．等价
  3. float * const p
  4. const float * const p
    所以，就懂了。
    const修饰值，就不能改变值。修饰地址，就不能改变地址。
