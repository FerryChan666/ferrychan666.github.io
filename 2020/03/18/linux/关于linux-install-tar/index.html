前言

在Linux的使用中，难免会使用下载，解压和安装。但它不会像windows系统那么直接了当。所以，需要用到一些命令。

了解

  1. wget URL //下载
  2. tar -zxvf <file.tar.gz> //解压
  3. ./<file.pl> //执行

说明

当我们在tar时，遇到

Not enought space to extract，我们可以将tar.gz（要解压的文件）复制到另外一个地方。
